# Crans Theft Auto 🚗🍷

Open world style GTA dans le vrai Crans-près-Céligny (VD).

- `index.html` (version principale, légère) : bâtiments et routes **OpenStreetMap**, relief et photo aérienne **swisstopo** (SWISSIMAGE) plaquée sur le sol et les toits
- `google.html` : variante avec **Google Photorealistic 3D Tiles** (clé Google Map Tiles API demandée au lancement, stockée uniquement dans le navigateur)

Pages statiques uniquement. Déploiement : importer le dépôt sur Vercel, sans aucun réglage.

Mission : retrouver les 6 bouteilles perdues du Château de Crans.
