# Crans Theft Auto 🚗🍷

Open world style GTA dans le vrai Crans-près-Céligny (VD).

- Bâtiments, arbres et relief : **Google Photorealistic 3D Tiles** (clé Google Map Tiles API demandée au lancement, stockée uniquement dans le navigateur)
- Routes, trafic, collisions et radar : **OpenStreetMap**
- Relief de secours : **swisstopo**

Une seule page : `index.html`. Déploiement : importer le dépôt sur Vercel, sans aucun réglage.

Mission : retrouver les 6 bouteilles perdues du Château de Crans.
